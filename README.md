# RUbot Frontend

## Overview

**RUbot** is a chatbot application designed to assist Rutgers University students by providing accurate information about various Rutgers programs and courses. It streamlines the process of obtaining course details and program information, eliminating the need to navigate multiple websites or documents. Additionally, RUbot offers a feature that helps users select a program and recommends classes based on their interests and experiences.

## Frontend Description

The frontend of RUbot is built using **Next.js** and **TypeScript**, ensuring a robust and scalable user interface. It leverages **NextAuth.js (Auth.js)** for managing authentication and maintaining the authentication state, providing a secure and seamless user experience.

The frontend contains several key pages:

- **Home Page**: The landing page for the application.
- **About Page**: Provides a detailed description of the application and explains how users can interact with it.
- **Chat Page**: The main highlight of the application, where users can interact with the chatbot and communicate with the AI agents.
- **User Profiles Page**: Allows users to manage their settings and preferences.

### Tech Stack

- **Next.js**: A React framework for server-side rendering and generating static websites.
- **TypeScript**: A typed superset of JavaScript that compiles to plain JavaScript.
- **NextAuth.js (Auth.js)**: An open-source authentication solution for Next.js applications.
